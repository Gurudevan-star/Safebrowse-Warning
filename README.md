# Safebrowse-Warning

SafeBrowse Warning helps users make informed decisions when visiting webpages that match configured warning criteria. When a matching webpage is detected, the extension displays a clear warning before the user continues. The warning gives the user the choice to return to the previous page or continue to the webpage. SafeBrowse Warning is designed to provide an additional layer of awareness while browsing without preventing users from accessing webpages they choose to visit. The extension operates in the background to detect relevant navigation events and display warnings when appropriate.
