Privacy Policy — SafeBrowse Warning Last Updated: October 4, 2026 SafeBrowse Warning is a browser extension designed to provide users with warnings when a webpage URL exhibits characteristics that may be associated with suspicious or potentially unsafe websites. 1. Information Accessed SafeBrowse Warning accesses webpage navigation information required to perform its security-warning functionality. The extension may process the URL and domain of webpages that the user attempts to visit. This information is used to evaluate characteristics of the requested web address. 2. How Information Is Used SafeBrowse Warning analyzes webpage URLs locally within the browser. The current version checks characteristics including: • Whether the connection uses HTTP or HTTPS • Potentially misleading internationalized domain names • Unusually deep subdomains • Account-related URL patterns • Certain encoded or numeric URL patterns • Demonstration suspicious-domain entries • Potential brand-name impersonation patterns When a URL meets one or more warning criteria, the extension displays a warning explaining why the URL was flagged. 3. Data Transmission The current version of SafeBrowse Warning does not send webpage URLs, domains, or browsing information to a remote server or third-party security service. URL analysis is performed locally within the browser. 4. Data Collection SafeBrowse Warning does not intentionally collect or sell users' browsing history. The extension does not intentionally collect: • Names • Email addresses • Passwords • Authentication credentials • Payment information • Personal identity information The extension processes webpage URL information only as required for its warning functionality. 5. Data Storage SafeBrowse Warning does not intentionally store users' browsing history on a remote server. The current security checks are performed locally. The extension requests browser extension storage permission for configuration-related functionality. No browsing history is intentionally transmitted to or stored by a remote service. 6. Data Sharing SafeBrowse Warning does not sell, rent, or share users' browsing information with advertisers or other third parties. The current version does not transmit URL information to external services. 7. User Control When a webpage triggers a warning, SafeBrowse Warning explains the detected signals and provides the user with choices. The user may return to the previous page or choose to continue to the requested webpage. The extension does not make the final browsing decision for the user. 8. Security Limitations SafeBrowse Warning is an additional security-awareness tool and does not guarantee that a webpage is safe or malicious. A warning does not necessarily mean that a website is malicious, and the absence of a warning does not guarantee that a website is safe. Users should independently verify websites before entering passwords, OTPs, financial information, or other sensitive information. 9. Changes to This Privacy Policy This Privacy Policy may be updated when the extension's functionality or data practices change. The latest version will be maintained at the publicly accessible URL associated with SafeBrowse Warning. 10.
